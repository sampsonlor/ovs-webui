# ADR 0002 可选的 STP/RSTP 运行态只读证据扩展

日期：2026-10-21。状态：**Accepted for isolated P1 prototype — 用户已认可方案并授权隔离实现与双架构测试**。接受范围不含生产部署或生成树执行。关联 #23 / #43；基础为已合并 PR #98，main `09d1347876b356d51e1011e15e2c63c650201014`。

## 背景

M2c3 已把当前执行权限、不可变 Bridge 配置绑定、双原生只读围栏和可信运行态来源整合为私有预检。其运行态仍按名称读取，不能证明对应的已配置运行对象 UUID、另一个协议确实未启用，以及该 ovs-vswitchd 的 IDL 当前已获 `ovs_vswitchd` 锁。配置计数相等和真实数据库连接均不能补齐这些证据。

检查 OVS 3.3.9 源码发现，同名且相同 datapath type 的 Bridge 可以沿用运行对象并替换 `br->cfg`；未持 IDL 锁的一条执行路径会直接返回；部分生成树 setter 失败只记录日志。因而不能把当前配置指针、MAC、`cur_cfg == next_cfg` 或 unixctl 对象存在分别提升为安装成功或执行授权。依据及行号见[方案的源码表](../implementation/SPANNING_TREE_RUNTIME_WITNESS_PLAN_v0.1.md#2-源码证据与补丁位置)。

## 拟议决定

评估一个默认不构建、须显式选择的 OVS **用户态只读扩展**。在既有 ovs-vswitchd Unix 控制 socket 上新增一个固定、私有、版本化的状态命令，输入仅为 Bridge UUID 和本次请求 nonce。它输出同一主线程采样中的运行对象实例、已完成配置绑定、实际协议启用状态、本地参数，以及 IDL 已处理的连接和锁状态。补丁不得改变生成树算法、setter 顺序、定时器单位、重试或数据库内容。

原型先固定 OVS 3.3.9 的源提交；3.7.1、4.0.0 必须分别移植并在 amd64/arm64 的实际构建上验证。原版 OVS、扩展缺失、构建不受信任或证据不足时，保留已有观察和草案能力，生成树执行继续关闭。mgrd 仍为 CGO-free Go，不新增 daemon、网络监听、通用命令代理或任意 JSON-RPC 接口。

该扩展是增加证据的候选手段。它报告的是 daemon 已处理到的状态，不能消除尚未收到的锁通知，也不能把外部 OVSDB 写事务与 IDL 锁归属原子绑定。读后变化、断连和锁丢失必须在后续执行设计中单独处理；本 ADR 不承诺仅靠该接口就能安全开放写入。

完整的接口、变更位置、测试矩阵、阶段退出条件和部署要求见[实现与测试方案](../implementation/SPANNING_TREE_RUNTIME_WITNESS_PLAN_v0.1.md)。P1 的固定源码实现和私有契约见[隔离原型说明](../implementation/SPANNING_TREE_WITNESS_PROTOTYPE_v0.1.md)；具体构建资格以完整 CI 报告为准。

## 备选路线和取舍

| 路线 | 评估结论 |
| --- | --- |
| 仅使用原版 OVS 的 show/status、配置计数和进程连接 | 继续用于既有观察；不足以提供上述完整绑定和锁证据，不能据此开放执行 |
| 可选的 ovs-vswitchd 只读扩展 | 用户选择的评估路线；增加与具体 OVS 构建绑定的维护和发布成本，先做隔离原型 |
| Go 读取进程内存、调试符号或根据 MAC 推导 UUID | 不采用；不是稳定、完整的受支持身份契约 |
| mgrd 获取、抢占或试探 `ovs_vswitchd` 锁 | 不采用；改变锁状态且不能证明另一个客户端持锁，破坏只读边界 |
| 扩展直接写配置或改变协议实现 | 不在本次授权和方案范围内；如证据仍不足，另行设计和审查 |

## 审查与接受条件

P0 方案已认可，当前进入 P1 隔离实现与测试；未部署扩展，不修改公共 API、权限模板或生产 caller。`bridge.spanning-tree.prepare` 继续无条件返回 `SPANNING_TREE_EXECUTION_PENDING`，不转换为执行操作。#23 / #43 和 Phase 1 保持未完成，#71 保持延期。

P1 必须完成 3.3.9 双架构只读原型和负向测试，再评审接入既有私有预检。之后才能设计独立密封执行操作、持久图预约、受保护写入和 High-risk Safe Apply。生产部署还需要具体构建、测试报告、安装与回退方案；本次隔离实现授权不等于部署批准。
